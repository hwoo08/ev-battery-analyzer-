# EV 배터리 잔존가치 분석기

<sub>EV Battery Residual Value Analyzer</sub>

사용 후 전기차 배터리 120대를 **재제조·재사용·재활용** 세 경로로 판정하는 시스템입니다.
안전성(셀 전압 편차·온도 이력·BMS 오류)을 SOH보다 먼저 검사하도록 설계해,
**SOH 80%를 넘겼는데도 재투입에서 제외되는 배터리 6대**를 걸러냈습니다.
판정 기준은 공개 자료를 참고해 직접 설계했습니다.

🔗 **웹 데모: https://hwoo08.github.io/ev-battery-analyzer/**
📊 **경로 판정 대시보드: https://hwoo08.github.io/ev-battery-analyzer/batch.html**

단순 SOH 계산기가 아니라, SOH·셀 전압 편차·온도 이력·BMS 오류·사용
이력을 종합해 100점 만점으로 점수화하고, 그 결과를 배터리 재제조/재사용
관점의 등급(재사용 적합 ~ 재사용 부적합)으로 판정합니다.

> ⚠️ 평가 기준은 실제 기업의 공식 판정 기준이 아니라, 이 프로젝트를 위해
> 자체 설계한 모델입니다. 자세한 산정식은 [`docs/evaluation_method.md`](docs/evaluation_method.md)
> 를 참고하세요.

## 두 가지 기능

### 1. 단일 배터리 진단
배터리 한 대의 상태를 SOH·셀 전압 편차·온도 이력·BMS 오류·사용 이력으로
100점 환산해 건강도를 평가합니다. → [평가 모델 문서](docs/evaluation_method.md)

### 2. 자원순환 경로 판정
입고된 배터리를 **재제조 / 재사용(ESS) / 재활용** 세 경로 중 하나로 판정합니다.

```
입고 배터리
    ├─▶ [1] 안전성 게이트 ─── 미달 ──▶ 재활용
    ▼
   [2] SOH 1차 분류
    ├── 80% 이상 ──▶ [3] 재제조 정밀 조건 ─┬─ 충족 ──▶ 재제조
    │                                     └─ 미충족 ─▶ 재사용
    ├── 60 ~ 80% ────────────────────────────────────▶ 재사용
    └── 60% 미만 ────────────────────────────────────▶ 재활용
```

핵심은 **안전성을 SOH보다 먼저 본다**는 점입니다. 잔존 용량이 많아도
셀 밸런싱·열 이력·BMS 이상이 있으면 전기차 재투입에서 제외됩니다.
샘플 120대 중 **SOH 80% 이상인데 안전성으로 탈락한 배터리가 6대** 나오는데,
SOH만으로 판단했다면 놓쳤을 사례입니다.

→ [판정 정책 문서](docs/routing_policy.md)

## 실행 방법

### 웹 버전

`index.html`을 브라우저로 열면 바로 동작합니다. 서버가 필요 없고,
평가 로직은 `assets/app.js`에 `main.py`와 동일한 산정식으로 구현되어 있습니다.
(두 엔진의 계산 결과가 샘플 4건 전부에서 소수점까지 일치하도록 검증했습니다.)

배포는 GitHub Pages를 사용합니다 → [`docs/github_deploy.md`](docs/github_deploy.md)

### 터미널 버전

```bash
# Windows
py main.py

# macOS / Linux
python3 main.py
```

메뉴:

```
[1] 배터리 정보 입력       [4] 자원순환 경로 판정
[2] 배터리 상태 분석       [5] 입고 배터리 일괄 처리
[3] 보고서 생성            [6] 종료
```

입고 배터리 120대를 한 번에 판정하려면:

```bash
python3 batch.py
```

샘플 데이터를 다시 만들거나, 두 엔진(Python/웹)의 판정이 일치하는지
확인하려면:

```bash
python3 tools/generate_sample_data.py   # 샘플 데이터 재생성
python3 tools/verify_engines.py         # 엔진 일치 검증 (Node.js 필요)
```

별도의 외부 라이브러리 설치 없이 Python 표준 라이브러리만으로 동작합니다
(Python 3.8 이상 권장).

## 메뉴 구성

```
[1] 배터리 정보 입력    - 차량/배터리 정보를 입력해 data/battery_data.csv 에 저장
[2] 배터리 상태 분석    - 등록된 배터리를 선택해 평가 리포트를 화면에 출력
[3] 보고서 생성         - 분석 결과를 output/ 폴더에 CSV/TXT로 저장
[4] 종료
```

## 입력 항목

| 항목 | 설명 |
|---|---|
| 배터리 ID / 차량명 | 식별용 |
| 사용기간 (년) | 배터리 사용 연차 |
| 누적 주행거리 (km) | 차량 총 주행거리 |
| 현재 SOH (%) | State of Health |
| 평균/최고 온도 (℃) | 배터리 온도 이력 |
| 셀 최대/최소 전압 (V) | 셀 밸런싱 상태 확인용 |
| BMS 오류 발생 횟수 | BMS가 감지한 오류 누적 횟수 |
| 급속충전 비율 (%) | 전체 충전 중 급속충전이 차지하는 비율 |

## 로드맵

1. ✅ **Python 계산 엔진** — 입력 → SOH/위험도/재사용 점수 → 결과 출력
2. ✅ **웹사이트** — 브라우저에서 즉시 진단, 점수 시각화
3. ✅ **자원순환 경로 판정** — 재제조/재사용/재활용 3분류, 안전성 게이트, 120대 일괄 처리
4. ⬜ **AI/ML** — 공개 배터리 열화 데이터로 SOH 추정 및 잔존수명(RUL) 예측

## 프로젝트 취지

사용 후 배터리를 재제조·재사용하는 관점에서는 SOH 하나만 보는 것이
아니라 상태를 종합적으로 평가하는 것이 중요합니다. 이 프로젝트는 그
문제의식을 바탕으로, 사용 후 전기차 배터리의 상태 데이터를 기반으로
잔존 성능과 재사용 적합성을 평가하는 프로그램을 설계·구현한
포트폴리오입니다.
